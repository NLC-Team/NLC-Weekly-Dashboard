Email notifications (optional)

Sign-in doesn't use email — everyone signs in with their email address and password. This section is only for one optional convenience: emailing admins when someone requests access, so you get a heads-up without checking the dashboard.

You don't need this to run the app. New access requests always show up in Staff & Roles with a red badge, whether or not email is set up.

Status: {% if mail.configured %}set up {% else %}not set up — that's fine; you'll still see requests in Staff & Roles.{% endif %}

If you do want the email alerts, two ways to connect (needs your Microsoft 365 admin's help — this firm's tenant currently blocks both by default):
• Direct send (no login): leave Username & Password blank. Host nlcfcpa-com.mail.protection.outlook.com, port 25, STARTTLS off. Requires your server's IP to be an allowed sender.
• Signed-in: Username = a full mailbox address (e.g. serviceaccount@nlcfcpa.com) + its password or app password. Host smtp.office365.com, port 587. Requires Authenticated SMTP enabled on the mailbox.
